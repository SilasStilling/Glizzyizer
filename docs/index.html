The four knobs

Everything you need, nothing you don't. Twist, hear it, move on.

Girth

Drives the signal into a tanh waveshaper. From subtle warmth to fat, harmonic crush.

Mustard

Tilt EQ. Roll it down for darker, smokier color — push it up for bright, biting top end.

Flame Boost

Toggles a presence push plus a high-frequency stereo widener. Instantly bigger, instantly hotter.

Serve

Output gain in dB. Match levels after the saturation so your A/B is honest.

Install

  1. Download the latest Glizzyizer-x.y.z-Setup.exe from the releases page.
  2. Run the installer (admin required — it copies the plugin into C:\Program Files\Common Files\VST3).
  3. In FL Studio: Options → Manage plugins → Find more plugins. Glizzyizer shows up under NewPlug.
  4. Drop it on a channel. Twist Girth. Smile.

Tested in FL Studio. Should work in any VST3 host on Windows x64.

Build from source

You'll need Visual Studio 2022 with C++ workload, and Git.

git clone --recursive https://github.com/SilasStilling/Glizzyizer.git
cd Glizzyizer
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release

The VST3 ends up in build\Glizzyizer_artefacts\Release\VST3\. To build the installer, see installer/README.md.
